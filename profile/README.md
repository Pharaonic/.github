## Why Pharaonic?

Not another framework. A toolbox.

- **Focused** — every package solves one problem, and solves it well.
- **Composable** — adopt one package or ten, without lock-in.
- **Natural** — APIs that feel native to PHP and Laravel.
- **Production-ready** — useful abstractions over clever ones.

<br>

## Philosophy

> Build the primitive once.
> Keep the API simple.
> Let developers compose the rest.
